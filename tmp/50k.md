# Как и куда проебать 50к рублей?

Совершенно случайно я получил заказ на быдлокод, за который мне обещали дать 50к рублей. Сумма это для меня не просто большая, а скорее заоблачная. Потому их надо потратить максимально разумно, чтобы не было мучительно больно!

Деньги надо потратить обязательно сразу и полностью, потому что в противном случае я их спущу на повседневную хуйню и мои мечты останутся нереализованными. Держать запас денег я не умею, потому советы вида "сохрани" для меня равноценны советам "сожги их".

Итак, в этом треде мы находим самые перспективные проекты, куда можно проебать 50к рублей.

# Снижение веса тушки

* Годовой запас Оземпика (и на этом деньги кончаются), но вдруг я похудею и начну шевелиться?
* Детали для велотренажера

# Улучшение вентиляции комнаты

* ручной 3D-сканер для сканирования оконных рам
* Реверсивный ESC для бесколлекторных движков
* Парочка ESP32 для управления вентиляторами
* Дешевая серва для закрытия жалюзей форточки
* Сами жалюзи их ближайшего хозмага
* Лобзик для вырезания фанеры
* Шуруповерт

# Охлаждение комнаты

* Теплообменник от камаза или что-то похожее массивное
* Метра 2 медной трубки
* Метр тонкой трубки
* Труборез
* Фреон или какой-то аналог
* Компрессор от холодильника
* Пусковые реле
* Пара цифровых датчиков (внутри и снаружи)
* Шуруповерт для наматывания трубок
* Дрель-перфоратор для стены дома

# Избавление от энергетиков

* Пару банок "спортпита"
* Аналог советского сифона (sodastream), чтобы газировать напиток
* Элементы Пельтье с теплообменником (готовый блок за 2000р на Али)

Современные энергетики - это пиздец из аспартама по завышенной цене и с вырезанием поджелудочной железы. Но куда без них? Так моя поджелудочная будет отваливаться чуть медленней

# Создание небольшого производства печатных плат

* Лобзик для нарезания фанеры и заготовок
* Дремель

* Лобзик
* Лазерный принтер
* Дремель

# Охладитель кровати

# Охладительная одежда

* Много силиконовых трубок и соединительные элементы
* Различные клеи на силиконовой/каучуковой/полиуретановой основе
* Вакуумные медные трубки, штук 5
* Несколько разных помп для прокачивания хладагента
* Две футболки
* Элементы Пельтье с теплообменником (готовый блок за 2000р на Али)

# Пофиксить дырку на жопе в штанах

* Купить новые штаны. Можно даже элитные Коттонс за 6000р
* Купить швейную машинку Brother за 30000р (дорого, зато старая мечта!)

# Сделать хранилище одежды

Так как новые трусы и футболки я постоянно покупаю, но потом не могу их найти, вероятно вся одежда попадает в потустороннее измерение. Надо сделать какой-то ящик для одежды. А лучше купить вешалку

* Вешалка для одержды за 1500р

# Прихуярить полочки по всем стенам

Чтобы добраться до окон, надо разобрать хлам. А чтобы разобрать хлам, его надо куда-то складывать. Пока идея придрелить все к стенам.

* Шуруповерт
* Дрель-перфоратор
* Много дюбелей
* Много саморезов 100-ок
* Много уголков
* Лобзик для вырезания полок из фанеры

# Установить бассейн для помывки

* Сам бассейн из ПВХ
* Трубы для прокладки из кухни (гибкие)
* Бочка для нагрева воды (или ведро)
* Кипятильник или индукционка для нагрева воды
* Циркуляционный насос
* Набор тапочек
* Загерметизировать пол

# Сделать стиральную машину на Сименсах

Чтобы не только иметь возможность помыться, но и постираться, то в бассейн можно будет установить стиралку. Я думаю, что ее можно сделать самому.

* Лобзик для вырезания барабана из фанеры
* Строительные шпильки в качестве направляющих
* Шаговик для кручения барабана (чтобы с редуктором не заморачиваться)
* Штук 5 мощных помп (рециркуляция, набор, слив воды, работа с порошком, работа с жидкой химией)

# Свет в комнате

Я достаточно плохо вижу, потому нуждаюсь в лампочках от 20к люкс, только при такой яркости я вижу в каком говне я живу.

* Лампочки за 1.5к рублей
* Разветвитель на 7 лампочек (штуки 3, в коридор, на кухню, в комнату)
* Драйвера для управления китайскими диодами (диоды уже есть)
* Штуки 3 esp32 для управления лампами
* УФ-лампы для генерации озона/дезинфекции когда меня нет
* Датчики присутствия
* Релюшки для силового управления

# Лазерный выжигатель по стенам

* Лазерный модуль на 30 ватт (40к рублей)
* Два шаговика и драйвера
* Много экструзивного алюминиевого профиля
* Пару катушек PLA

# Анальные радости

* Тупо зайти на Али и все просрать на дилдаки, которые пытаются быть похожими на Плохого Дракона. Счастья они не принесут, но хотя бы будут напоминать, что у меня когда-то были на них деньги

# Установка муляжей видеокамер на улице

Меня достали уроды, которые курят на улице/в подъезде

* Муляж камеры (2 штуки)
* Настоящая камера (если сопрут муляж)
* Таблички "ведется видеонаблюдение" и "не курить"
* Дюбели и саморезы
* Шуруповерт
* Дрель-перфоратор

# Поющий фонтан

* Штук 20-30 небольших помп для воды. Увы, сложно сказать какие нужны, потому проще взять разных видов
* Что-то для управления индуктивной нагрузкой, вроде сборок Дарлинктона
* Пару внешних генераторов ШИМ по 16 каналов
* Может быть 10-20 дешевых серв для управления струйками
* Несколько лазерных модулей на 5mw с разным спектром
