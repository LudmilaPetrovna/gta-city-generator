# Смотрелка геопространственных данных

Нужно сделать что-то вроде GoogleMaps, только для мира игры GTA:SA

## Цели проекта:

* Отображение гео-пространственных данных игры GTASA
* Работа в онлайн и оффлайн-режимах
* Поддержка интеграции с запущенной игрой (http, websocket)
* Легкий импорт данных
* Легкий экспорт данных (txt, kml, pbf?, формат SasPlanet)
* Примитивные функции редактирования данных
* Захват данных из игры в реальном времени
* Просмотр различных датасетов (используемые модели, где используются текстурные архивы)
* За все охуенное против всего хорошего и нормального

## Конкретные задачи

Чтобы не делать проект в вакууме с никому ненужными фичами, нужно поставить конкретные цели, которые можно героически решить, чтобы на выходе проект делал хоть что-то полезное.

### Импорт существующих радарных карт:

* Считаем, что радарная карта - это картинка с привязкой к координатам -3000х3000..3000..-3000
* Импортируем как растровый слой с текстовым описанием и метаданными (ссылками / описаниями)
* Импортер ресайзит тайлики в чуть большее разрешение, подгоняет под проекцию
* После завершения импорта базового слоя, запускаем процесс ресайза картинок в "пирамидку"
* Добавить как слой в свой раздел, к примеру, "подложки".

### Импорт всех коллизий с именами и данными:

* Засунуть все коллизии в 3dsmax
* Каждую модельку трансформировать в пространстве столько раз, сколько она встречается в IPL
* Отрендерить с видом "сверху", натянув текстуру высот (или как-то иначе отрендерить карту высот)
* Рендер порезать на этажи и засунуть в autotrace, на выходе получить векторный полигон(ы)
* Пустить облет камеры вокруг трасформированной модельки, получить анимированную гифку для превью
* Сделать цветной рендер с кодированием материалов (?), сохранить картинку
* Повторить все шаги, но с моделями теней
* Повторить все шаги, но с bounding spheres + bounding box
* Высрать датасет с координатами этих полигонов и суб-слоями для теней и габаритов

### Импорт всех машинок из IPL:

* Делаем простой датасет с координатами и ссылками на иконки (не картинки)
* Можно сделать превьюшку каждой машинки в виде гифки с крутящейся машинкой
* Под иконкой рисуем стрелочку, так как у точки есть heading

### Импорт всех ENEX из IPL:

* Датасет с иконками перехода
* На каждой иконке лежит гиперссылка
* По клику на гиперссылку мы улетаем в интерьер

## Функции редактора:

* Можно потыкать объекты и посмотреть их координаты или ID
* Можно подвигать объекты или внутренние объекты
* Можно добавить свой датасет как слой
* Добавить параметр из игры как источник данных
* Прочитать данные слоя (полученные или сохраненные ранее)
* Сохранение данных при локальной работе
* Можно посмотреть превью по объекту, перейти по ссылке, открыть панораму
* Можно грабить корованы

## Типы данных / глоссарий:

* **Точка в пространстве**: x,y,z,interior,heading
* **Путь**: состоит из точек в пространстве
* **Линия**: состоит из данных для отрисовки (НЕ ТОЧЕК!), имеет свою окантовку
* **Полигон**: замкнутая линия, имеет окантовку и заливку
* **Картинка**: png/jpeg картинка, имеющая 2 точки привязки к карте (или одна точка + размер)
* **Растровый слой**: много картинок, но склеенные в единый набор тайлов и отмасштабированные пирамидкой
* **Иконка**: картинка с точкой привязки, отрисованная в одном разрешении и не скейлящаяся
* **Моделька**: gltf-файл
* **Превью модельки**: или скриншот с угла, или анимированная гифка, в виде всплывающего окошка
* **Панорама**: текстура для натягивания на сферу, порезанная на тайлики с разными разрешениями
* **Текст-описание**: простой текст с переводами строк, без форматирования
* **Табличка**: табличные данные вроде CSV, описывающие произвольные данные в слое
* **Шаблон**: вывод табличных данных о объекте в виде красивого попапа, вместо текста-описания
* **Гиперссылка**: адрес на точку в пространстве, возможно с уровнем детализации. Можно кликать для перехода.
* **Гиперссылка-панорама**: кнопка на карте, открывающая окно панорамы
* **Гиперссылка-действие**: кнопка на карте, провоцирующая событие в игре (запуск миссии, перенос персонажа)
* **Интерьер**: смещение на 2х-мерной карте по оси Х (экватор) на 6км, чтобы увидеть модели без наложения
